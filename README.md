# apkParkir
Aplikasi Parkir ini adalah sistem manajemen parkir berbasis desktop yang dikembangkan menggunakan Visual Basic (VB) dan MySQL sebagai database. Aplikasi ini dirancang untuk membantu pengelolaan data kendaraan yang masuk dan keluar di area parkir, serta mencatat durasi dan biaya parkir secara otomatis.

✨ Fitur Utama:
🔐 Login pengguna (Admin dan Petugas Parkir)

🚗 Pencatatan kendaraan masuk dan keluar

⏱️ Perhitungan otomatis durasi dan biaya parkir

🧾 Cetak struk parkir (opsional)

📊 Laporan harian dan bulanan

🗃️ Manajemen data kendaraan, tarif, dan pengguna

🛠️ Teknologi:
Bahasa Pemrograman: Visual Basic (VB.NET / VB6 tergantung versi)

Database: MySQL

Crystal Report (jika ada cetak laporan/struk)

📌 Tujuan:
Aplikasi ini dibuat untuk mempermudah pengelolaan area parkir di tempat umum seperti mall, kantor, sekolah, atau area publik lainnya dengan sistem digital yang efisien.
